# Review verdict boundaries

The approved change clarifies the existing verdict policy. A machine check marked FAIL is evidence of a defect, not a final reject verdict. A first take with repairable technical or visual defects receives fix; confirmed content red lines and a failed single re-shoot receive reject. Missing history is not evidence of a failed re-shoot.

The skill keeps one ordered decision procedure, and its checklist points back to it. Character-specific checks apply only to character briefs. The extraction script and shared hard rules stay unchanged.

Validation covers the retained first-take failure in Cursor, a red-line decision, and a failed re-shoot decision. Repository checks cover structure, manifests, the existing extraction script and the new eval definitions. No paid render is needed. A local Cursor test loads the edited skill; no release is part of this change.
