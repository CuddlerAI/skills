# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment, personal attacks and sexualised content are not welcome anywhere in this project, including issues, pull requests and examples.

To report a problem, write to support@cuddler.ai, which reaches the Cuddler team and not only the maintainer named in `.github/CODEOWNERS`; if it involves an account or credits, use the private report described in [SECURITY.md](SECURITY.md) instead. Reports are handled confidentially.
